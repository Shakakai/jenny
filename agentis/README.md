# Agentis

Agentis is a macOS desktop application that helps non-technical salespeople create, run, and visualize Mesa agent-based models using LLM-generated code. It provides a guided wizard interface for describing customer scenarios and automatically generates runnable Python simulation code.

## Prerequisites

- **macOS 13+** on Apple Silicon (M1/M2/M3)
- **Homebrew**
  ```bash
  /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
  ```
- **Rust**
  ```bash
  curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
  ```
- **Tauri CLI**
  ```bash
  cargo install tauri-cli --version "^2"
  ```
- **Node.js 20**
  ```bash
  brew install node@20
  ```
- **pnpm**
  ```bash
  npm install -g pnpm
  ```
- **uv** (Python package manager)
  ```bash
  curl -LsSf https://astral.sh/uv/install.sh | sh
  ```
- **Python 3.11**
  ```bash
  uv python install 3.11
  ```

## Setup

```bash
git clone <repo-url>
cd agentis

# Copy environment file and add your Anthropic API key
cp .env.example .env
# Edit .env and set ANTHROPIC_API_KEY=sk-ant-...

# Install frontend dependencies
pnpm install

# Install backend dependencies
cd backend && uv sync && cd ..
```

## Development

```bash
make dev
```

This starts three processes simultaneously:
- **FastAPI backend** on port 57431 (hot-reload enabled)
- **Vite dev server** on port 1420 (React frontend)
- **Tauri** opens the native macOS window pointing at the Vite dev server

## Building

### Build the backend sidecar

```bash
make build-sidecar
```

Compiles the Python FastAPI backend into a standalone binary using PyInstaller. The binary is placed at `src-tauri/binaries/agentis-backend-aarch64-apple-darwin` (or `x86_64` on Intel Macs). This binary is bundled into the macOS `.app` and spawned automatically at runtime.

### Build the full macOS app

```bash
make build
```

Runs `build-sidecar` first, then compiles the Tauri app into a native macOS `.app` bundle inside `src-tauri/target/release/bundle/macos/`.

### Clean build artifacts

```bash
make clean
```

Removes `src-tauri/target/`, `dist/`, and compiled sidecar binaries.
